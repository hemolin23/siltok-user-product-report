# Siltok 产品与研发问题评审

面向产品与研发会议的用户反馈复核网页，按问题优先级组织证据、影响、排查方向与复测标准，并保留原始记录和附件。

## 查看网页

- [公开网页](https://hemolin23.github.io/siltok-user-product-report/)
- 本地预览：在项目目录运行 `python3 -m http.server 8000 -d dist`，然后打开 `http://localhost:8000`

## 项目内容

- `dist/`：可直接部署的静态网页和配图。主报告按 P0/P1/P2 展示问题，并内嵌反馈、云端公测、体验任务与镜头库；四条正式反馈的非联系字段、23 件获授权的原始附件，以及云端公测文档文字全文可展开核对。
- `docs/report.md`：历史文字版工作汇报，包含此前的运营统计口径；公开网页已改为产品与研发会议版本。

## 数据口径与权限

飞书定向测试表 2 条、真实业务表 2 条，合计 4 条正式记录、3 位具名用户；另有专业 CG 导演转述及独立云端公测文档，不混入人数。仓库现为公开；资料网页不展示手机号和微信号，23 件反馈附件已由用户确认可公开。部分原始资料链接仍需要原系统权限。
