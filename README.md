# Siltok 用户运营与产品技术汇报

面向产品与技术团队的阶段性工作汇报网站，覆盖用户运营漏斗、案例反馈、产品判断、功能与性能区别，以及尚未规划或定义不清的问题。

## 查看网页

- [在线预览（需相应访问权限）](https://siltok-user-product-report.qingyu-lu-ai.chatgpt.site)
- 本地预览：在项目目录运行 `python3 -m http.server 8000 -d dist`，然后打开 `http://localhost:8000`

## 项目内容

- `dist/`：可直接部署的静态网页和配图。主报告的“资料正文与案例拆解”板块已内嵌反馈、云端公测、体验任务与镜头库；四条正式反馈的非联系字段、23 件获授权的原始附件，以及云端公测文档文字全文可展开核对。`sources.html` 和对应独立页面保留为便于单独分享的入口。
- `docs/report.md`：完整的文字版汇报，包含统计口径、反馈分析和证据链接。

## 数据口径与权限

公开微信联系方式下限为 693 个；各渠道建联数合计 238 人次，**未跨渠道去重**；愿意测试者 18 人，其中 11 人已签协议、3 人未签、4 人内部免签。详情、局限和来源见文字版汇报。仓库现为公开；资料网页不展示手机号和微信号，23 件反馈附件已由用户确认可公开。部分原始资料链接仍需要原系统权限。
